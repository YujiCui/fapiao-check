# fapiao-check（发票体检）

一个 Agent Skill。读一家企业一段期间的发票清单，跑九条勾稽和风险筛查规则，输出异常清单和一页摘要。

脚本做能算清的检查，模型只复核要读语义的行，定性和签字留给执业人员。

## 安装

克隆到 skills 目录，以 Claude Code 为例：

```bash
git clone https://github.com/YujiCui/fapiao-check.git ~/.claude/skills/fapiao-check
```

在 Python 3.12 上测过。读 `.csv` 只用标准库，读 `.xlsx` 需要 `openpyxl`。

## 用法

在 agent 里说「发票体检」，给出清单路径、企业全称、税号、主营业务和检查期间。完整流程见 [SKILL.md](SKILL.md)。

也可以只跑脚本：

```bash
python check.py 清单.xlsx --side in --name "企业全称" --taxid 税号 --start 2026-07-01 --end 2026-09-30
```

清单是 `.xlsx` 或 `.csv`，一行一张票或一行一条明细都行；查销项用 `--side out`。输出两份文件，默认放在清单同目录：`<清单名>_异常清单.csv` 和 `<清单名>_摘要.md`。

用仓库里的虚构数据试跑：

```bash
python check.py 示例清单.csv --name 示例精密制造有限公司 --taxid 91000000MA0000001R --start 2026-07-01 --end 2026-09-30
```

应打印 `OK rows=13 invoices=11 hits=11 not_run=-`。

## 查什么

| 代码 | 规则 |
|---|---|
| R1 | 金额+税额≠价税合计；金额×税率≠税额 |
| R2 | 重复发票 |
| R3 | 状态含作废、红冲、异常、失控；风险等级不是正常 |
| R4 | 抬头或税号与本企业不符 |
| R5 | 18 位税号校验位不对，或位数异常 |
| R6 | 税率不在常见集合，或是历史税率 |
| R7 | 开票日期为空、无法识别、不在检查期间 |
| R8 | 整票价税合计不低于 5 万且是 1 万的整数倍 |
| R9 | 品目含敏感词（咨询、会议、推广、劳务；餐饮、娱乐、贷款利息、福利等） |

R8、R9 是提示性的，要人工或模型对照主营业务复核。税率集合、阈值、敏感词在 `check.py` 顶部。

## 现状和限制

- 没在电子税务局的真实导出表上验证过。表头别名按常见叫法写，未对照真实导出核对；认不出的列会列在摘要的「没跑或没跑全的规则」里。
- 税率集合、敏感词和金额阈值是作者自定的，未经执业人员审核。
- 不查对方是否非正常户、业务是否真实、资金是否回流。
- 输出只写「待核对」，不下定性结论。
- 脚本在本机运行、不联网。把清单交给大模型做语义复核之前，先确认客户数据能不能出本机。
